Monastery360 — Custom Image Directory
=============================================================================

This directory is designated for your own custom photos and 360° panoramas.

HOW IT WORKS:
Any image placed in this folder will AUTOMATICALLY override the default image
on the website with zero configuration needed.

SUPPORTED IMAGE FORMATS:
- JPEG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)

IMAGE NAMES YOU CAN OVERRIDE:
-----------------------------------------------------------------------------

  - pemayangtse.jpg     (Pemayangtse Monastery card)
  - tashiding.jpg       (Tashiding Monastery card)
